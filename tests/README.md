This directory contains all tests for the application.

- `test_cepstrum.py`: Unit tests for Mel Cepstrum calculation.
- `test_db_handler.py`: Unit tests for database interactions.
- `test_main_flow.py`: Integration tests for the end-to-end voice signature process.
